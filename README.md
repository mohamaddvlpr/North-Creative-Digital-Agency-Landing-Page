# North — Creative Digital Agency Landing Page

A modern and responsive creative agency landing page built with **HTML** and **Tailwind CSS**.

The project focuses on clean typography, minimal layouts, responsive design, and a strong visual identity. It includes a hero section, navigation, agency introduction, design approach, selected projects, and responsive content sections.

### ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern and minimal UI
* Built with Tailwind CSS utility classes
* Creative agency hero section
* Responsive navigation
* Brand and project showcase sections
* Font Awesome icons
* Responsive typography and spacing
* Image-based portfolio sections

### 🛠️ Technologies

* HTML5
* Tailwind CSS
* Font Awesome

### 🎯 Purpose

This project was created to practice building a modern, responsive landing page with **Tailwind CSS**, focusing on layout structure, responsive utilities, typography, spacing, and visual hierarchy.
